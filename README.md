# 🌍 Tourism Management System

A web-based **Tourism Management System** developed to simplify and digitize the traditional tour booking process. The system provides an online platform where users can explore tour packages, make booking requests, manage bookings, and submit feedback, while administrators can manage tour packages, bookings, users, and feedback.

---

## 📌 Project Overview

The Tourism Management System provides a centralized platform for managing tourism services.

Users can:

- Register and Login
- Browse available tour packages
- View tour details
- Select preferred travel dates
- Book tour packages
- View booking status
- Cancel bookings
- Submit feedback and complaints

Administrators can:

- Login securely
- Manage tour packages
- View booking requests
- Approve or reject bookings
- Manage user information
- View feedback and complaints
- Generate and manage tourism-related records
